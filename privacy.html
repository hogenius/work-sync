개인정보처리방침 / Privacy Policy

work-sync는 개발자 본인만 사용하는 개인용 도구입니다.

  • Google Tasks API(https://www.googleapis.com/auth/tasks)로 사용자 본인의 할 일 목록만 읽고 씁니다.
  • 데이터는 사용자 PC와 사용자 본인의 Google 계정 사이에서만 오갑니다. 외부 서버로 전송·저장·공유하지 않습니다.
  • 인증 토큰은 사용자 PC에만 저장되며, Google 계정 설정에서 언제든 접근 권한을 취소할 수 있습니다.

work-sync is a personal tool used only by its developer. It reads and writes only the user's own Google Tasks via the Google Tasks API. Data moves only between the user's computer and the user's Google account; nothing is sent to, stored on, or shared with any third-party server. Access can be revoked at any time from Google Account settings.

Google API에서 받은 정보의 사용은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 따릅니다.
